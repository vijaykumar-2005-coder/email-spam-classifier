# Email Spam Classifier

A machine learning project that classifies text messages as **Spam** or **Ham (Legitimate)** using TF-IDF and Linear Support Vector Machine (SVM).

## Features
- Text message spam detection
- Machine learning model comparison
- Interactive Streamlit dashboard
- Prediction history and CSV export
- Model performance visualizations

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- TF-IDF Vectorization
- Linear SVM
- Streamlit
- Matplotlib

## Model Performance
- Accuracy: 97.78%
- Spam Precision: 96.55%
- Spam Recall: 85.50%
- Spam F1-score: 90.69%

## Run Locally

1. Clone this repository.
2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the dashboard:

   `streamlit run app.py`
